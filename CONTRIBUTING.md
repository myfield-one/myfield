# Contributing

Thank you for helping improve MyField.

## Where to report

| Topic | Where |
| --- | --- |
| MyField, Keychain, Turn Field, Card Field, Slide Field, website, and others | Issues in this repository |
| `@myfield/sdk` code or API | [myfield-one/sdk](https://github.com/myfield-one/sdk/issues) |
| `did:mfid` specification or library | [myfield-one/mfid](https://github.com/myfield-one/mfid/issues) |
| Card Field source code | [myfield-one/card](https://github.com/myfield-one/card/issues) |
| Security vulnerabilities | Private report, see the [security policy](https://github.com/myfield-one/.github/blob/main/SECURITY.md) |

If you are not sure, open the issue here. We may transfer it to the right
repository.

## Before you open an issue

- Search existing issues first.
- Include the product, version, browser or OS, and steps to reproduce.
- Remove private data from screenshots and logs. Never post recovery phrases,
  passphrases, keys, tokens, or personal content.

## How issues are handled

1. A maintainer triages new issues and adds labels for product, type, and
   status.
2. Confirmed issues are tracked internally. The public issue stays the place
   for updates.
3. When a fix ships, we comment with the release and close the issue.

## Code contributions

The MyField platform source code is not public, so this repository does not
accept code pull requests. Pull requests that fix documentation in this
repository are welcome. For the SDK, mfid, and Card Field, see the
contribution notes in each repository.

## Conduct

Everyone taking part must follow the [Code of Conduct](https://github.com/myfield-one/.github/blob/main/CODE_OF_CONDUCT.md).
